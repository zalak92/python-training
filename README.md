# 2-Week Python for AI Beginner Training

Welcome! This repo is a 14-day Python training plan focused on essentials for Artificial Intelligence (AI) and Machine Learning.

## Structure

- **day_01.md** to **day_14.md**: Daily practice, explanations, and exercises.
- **README.md**: Overview and instructions.

## How to Use

1. Start with `day_01.md` and proceed day by day.
2. Each file includes explanations, code examples, and exercises.
3. Practice by writing code, reading comments, and completing exercises.

## Requirements

- Python 3.x
- Recommended: Jupyter Notebook or any IDE
