# 🐍 Complete 2-Week Python Training Program

> **For:** IT Infrastructure Professionals Moving to AI/ML  
> **Level:** Absolute Beginner to Intermediate  
> **Prerequisites:** Basic IT knowledge (Terraform/Bash/Cloud exposure is a bonus)  
> **Goal:** Read, Write, and Modify Python code confidently  
> **Daily Time Commitment:** 2-3 hours  

---

## 🎯 What You Will Learn

| Week | Focus | Outcome |
|------|-------|---------|
| **Week 1** | Python Fundamentals | Write basic Python scripts, understand data structures, control flow |
| **Week 2** | Intermediate Python for AI | Handle files, call APIs, use NumPy/Pandas, visualize data |
