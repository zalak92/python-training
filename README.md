## 🔧 Setup (Day 0)

### Install Python

**Windows:**
1. Go to https://python.org/downloads
2. Download Python 3.12+
3. CHECK "Add Python to PATH"
4. Click Install

**Mac:**
```bash
brew install python3

**Linux:**
sudo apt update && sudo apt install python3 python3-pip

Verify:

python --version
pip --version

Install Libraries

pip install jupyter numpy pandas matplotlib requests openpyxl seaborn

How to Run Code

# Option 1: Terminal
python filename.py

# Option 2: Jupyter (recommended)
jupyter notebook

# Option 3: Interactive
python
>>> print("hello")
>>> exit()
